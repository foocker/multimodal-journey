# 实验

一个实验目录围绕一个可验证问题，包含配置、执行代码、输出解释和复现命令。

| 实验 | 类型 | 状态 |
|---|---|---|
| [单位交付成本](2026-11-19-compute-budget/README.md) | 假设值的确定性算术演示 | 已运行；没有模型测量 |
| [基础模块探针](2026-11-22-foundation-probes/README.md) | 形状/因果/RoPE/注意力/流匹配/缓存依赖 | 已运行；没有真实网络/速度/质量测量 |

大型 run 输出放 `runs/` 或外部存储。提交的摘要应记录环境、代码版本、输入版本、指标和失败情况；不要只保留最好的一次。
