# 可控性提高后，单次更贵是否仍值得？

类型：**假设演算**。没有运行模型，没有实际厂商报价，没有测量交付可用率。

## 配置与复现

Python 3.10+，只用标准库，无随机性。输入为 [config.json](config.json)，方法见 [算法说明](../../algorithms/compute-budget/README.md)。

```bash
python experiments/2026-11-19-compute-budget/run.py
python experiments/2026-11-19-compute-budget/run.py --check
```

## 结果的含义

两种假设情景都交付 10 条视频：第一种生成单价 1.2、可用概率 25%；第二种单价 1.8、可用概率 50%。同样假设审片 45 秒、每条后期 8 分钟、人工 60/小时。

公式结果分别为每条交付 15.8 和 13.1 个假设货币单位。它说明单次更贵与整体更省可以同时发生，前提是可用率等假设成立。完整结果见 [results.json](results.json)。

## 限制和下一步

可用率不是从模型测得；各次生成独立的假设通常过强。没有考虑排队、固定成本、任务难度变化、失败退款和客户返工。后续用固定任务集记录实际候选数与人工时间后，才能估算业务成本。没有依据把本结果当成某个产品的 ROI。
