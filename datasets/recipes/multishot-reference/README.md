# 多镜头与主体参考：最小数据配方

状态：制作方案，尚未采集真实数据。样例全部手工构造，未附真实人物或第三方视频。

## 样本单位

一个 scene 包含全局主体/环境说明和至少两个镜头。每个镜头记录提示、可访问的源素材标识、镜头时间和需保持/需改变的属性。参考图只绑定明确的主体 ID，避免多个“同名人物”混淆。

## 制作步骤

1. 确定使用场景：评测多镜头连贯还是训练参考控制，先固定目标与评价标准。
2. 选取自有或明确授权素材，记录来源、许可/授权、版本和使用范围。无法确认训练权利的素材进入待确认区。
3. 按原始视频划分 scene 和 shot，保留全局与镜头级描述；质量检查覆盖剪辑边界、遮挡、字幕和低运动样本。
4. 标注主体 ID、衣着、背景、镜头运动、动作与声音；明确需要保持和允许改变的内容。
5. 按原始素材/主体分组做 train/validation/test 划分，去重后才生成图像参考与目标镜头对。
6. 固定一套人工抽检标准，记录歧义、漏标和参考泄漏；发布前检查使用权与个人信息处理要求。

## 最小验收

- 记录符合 [schema](../../schemas/scene-record.schema.json)，全局/镜头 ID 唯一且可关联。
- 每份真实素材有来源与使用权记录；每份生成素材有生成模型版本、输入和必要的随机参数记录。
- 划分依据原始来源，不能只随机打散镜头。
- 评分分别覆盖主体一致性、动作遵循、镜头连贯和非目标内容保持。

当前只提供 [合成格式样例](../../examples/synthetic-scenes.jsonl)；它不能用于宣称真实模型效果、泛化能力或商业可用率。
