# 来源登记

- [论文登记](papers.json)：稳定 ID、正式标题、阅读版本、PDF URL、笔记和文件校验信息。
- [非论文来源](web.json)：官方项目/产品页、代码入口、媒体线索与用户工作假设。
- [代码实现登记](code.json)：在来源 ID 下补充固定 commit、用途、源码/配置入口、许可证与阅读范围；当前 10 个仓库的 11 份固定版本记录、44 个入口，均未执行运行验证。LTX 原系列与当前版本分开登记，不能互套模型配置或许可证结论。

一个来源只登记一次。URL 和 PDF 版本分开记录；下载版本的 SHA-256 只用于文件身份验证。论文公开不等于代码、权重和数据全部开源。

来源日期使用可核对的首次公开或实际访问日期；未知作者、URL 和发布日期保留为空，不自动推断。只有实际查看过的来源才写 checked_on，后续页面可能变化。
