# 对用户摘录的核查与修订

日期 2026-11-22。原输入保留在 [talk2deepseek.md](../../talk2deepseek.md)；其末尾两组 RayFlow/2.5 架构段落重复，当前知识只维护一份，不删除原始对话材料。以下是本轮核查范围，不声称全文逐句审核。

| ID | 原摘录说法或风险 | 当前结论与依据 | 影响块 |
|---|---|---|---|
| C22-01 | 因果 decoder 标准做法为转置卷积后裁尾 k−1 | MAGVIT-v2 v3 p.5 为上采样后去开头 s−1，且使用 depth-to-space；不可用裁尾量替代全网依赖证明 | M01 |
| C22-02 | 压缩比始终 1/64 | 1.0 v2 p.4 的 1/64 为长序列元素比；保留首帧后有限 F 有修正，图像为 1/16 | M01、解析探针 |
| C22-03 | 解耦成本 `(HW)²+T²` | 需要乘帧数/位置数：`T(HW)²+HW T²`；窗口时空另乘窗口面积 m | M03 |
| C22-04 | 窗口时空 attention reshape 为 `[B×nwin×m,T,d]` | 该写法是逐位置时间 attention；窗口时空候选为 `[B×nwin,Tm,d]`；1.0 p.4/图2 未公开全部具体排列 | M03 |
| C22-05 | 文本主要出 K/V，梯度先 Q 后 K/V | MMDiT 联合自注意力两模态均出 QKV；梯度同时按计算图求导，cross-attention 另作区分 | M03、M09 |
| C22-06 | 因果 mask 足以永久 KV-cache，成本自然线性 | 历史/条件/timestep/位置/权重依赖须固定；新块每步仍算 QKV，全历史查询仍可累计二次，固定窗口才进一步限制增长 | M06、M10 |
| C22-07 | 1.5 Pro 已明确指定层双向交叉注意力、modality embedding | 本轮 v3 pp.1–2 只足以确认 dual-branch/joint module 和整体流程；细层公式保留为候选设计 | M05、M00 |
| C22-08 | Tarsier2 为 SigLIP＋MLP＋Qwen2，逐帧编码 | 固定 Tarsier2 v1 p.6/Table12 写从 Qwen2-VL-7B 初始化；不能套旧 Tarsier 结构，也未据此补造所有视觉算子 | M11、论文笔记 |
| C22-09 | Tarsier2 原始训练冻结视觉 encoder | 原文 pp.8–11 写全组件/全参训练；1.0 v2 p.7 是其下游 caption 适配冻结视觉 encoder，两种设置分开 | M11 |
| C22-10 | SFT-2 为 5 万条数据 | Tarsier2 v1 p.9 为 50K 指令和 150K 配对；p.36 预训练帧下界与正文不同，保留差异 | M11、论文笔记 |
| C22-11 | Seedance 1.0 已用 DanceGRPO，后续为固定核心组合 | 1.0 v2 p.12 §4.4.3 写直接最大化复合奖励并比较 DPO/PPO/GRPO；引用不证明采用，2.5 reward 身份未知 | M09、VG-022 |
| C22-12 | ODE 完全没有随机性，无法产生不同输出 | 固定初始噪声的 ODE 轨迹确定，但不同噪声仍有多样性；SDE 还用于定义可计算的随机转移策略密度 | M09 |
| C22-13 | RewardDance 解决/杜绝 hacking，高奖励方差证明多样性 | 作者实验支持特定范围的改善；奖励方差不等于样本多样性，仍需独立人工留出与模板率检查 | M09 |
| C22-14 | β 单独决定 DPO 稳定性，0.1 可直接判为保守 | β 与目标缩放/隐式正则有关，还受 lr、步数、margin、长度处理影响；本仓库不照抄绝对判断 | M09 |
| C22-15 | 2.5 的白模必走 3D encoder、时间戳编辑必走 KV-cache | 官方只披露能力；渲染 2D 帧/结构 adapter、inpainting/合成等均为可能路线，不能认定唯一内部实现 | M00、M07、M08 |
| C22-16 | 可变参考输入等于任意数量无额外成本 | 官方上限为 30/10/10 文件；token 数、质量与成本取决编码、压缩、绑定，Phantom 不证明 50 路部署 | M07、M12 |
| C22-17 | 参数形状兼容就能换分辨率、换基座模块 | 网格可变化不等于分布/质量已适配；Seedance 48 通道与 Wan 16 通道、patch、文本接口不同 | M03、M12 |
| C22-18 | 2.5 任何入口可无限续写、API 现在已开放 | 发布页写多轮，产品页写延长两次；7月“API近期上线”不能证明11月当前开放状态 | M00 |
| C22-19 | 尺度定律说明无限增大最好、公式系数可跨预算单位套用 | 只在作者设置范围解释拟合；需要固定数据、优化超参、计算单位并用 pilot 吞吐换算 | M03、M13 |

本轮未确认 2.5 参数量、具体训练数据规模、奖励/caption 模型、精确窗口/RoPE/codec 或当前价格。`unverified` 不表示这些实现不可能存在；候选架构单列为我们的方案。
