# 设计深化中的修正

日期2026-11-22，文档状态draft。

| 项 | 旧风险 | 修正与影响 |
|---|---|---|
| KD-01 | Wan轻量路线被读成完整音视频方案 | 明确保留Wan单能力路线；完整联合设计选LTX原系列，潜空间和训练分开 |
| KD-02 | 用当前LTX仓库中的后续型号反推原论文实现 | 固定2026-01源码commit，核对/8、/32、128通道、音频25Hz；不套LTX2.5文本/codec |
| KD-03 | 将原系列源码许可默认写成当前Apache | 原历史commit根LICENSE为LTX-2 Community License，单独登记；当前commit的许可结论不回填到历史版 |
| KD-04 | AlcheMinT equation5被直接编成旋转线性恒等式 | 一般R(aθ+bφ)不等于aR(θ)+bR(φ)；缺实现澄清，首版改用显式时间bias并标为候选 |
| KD-05 | VideoCoF的“reason then edit”被理解为严格两次串行采样 | 论文source固定，reason与target联合去噪；本文两阶段是为可检查性做的新设计 |
| KD-06 | 将首末可见帧连成一区间等同精确出场标签 | 数据接口保留多区间/逐帧可见性、遮挡置信度，训练缺席与重叠样本 |
| KD-07 | 增加文件上限等于证明50路质量 | 明确摘要token预算与文件容量只表示可输入，细节/音色保持列未验证门槛 |
| KD-08 | 720帧直接代入要求1+8k的VAE | 模型内部721，交付裁720，padding映射与音频时长同步；不能随意丢最后latent |
| KD-09 | 新增视觉编辑任务自动得到联合音频编辑 | 保留音轨、重生音轨、音频局部编辑分任务；源音轨可作固定条件/最终直接复用 |
| KD-10 | subject标签被当成每个空间query已知的归属 | 无空间条件时只做镜头级主体粗筛，通过embedding与训练学习绑定；空间硬mask依赖推理可获得的布局/跟踪/预测区域 |
| KD-11 | 32个音频摘要足以逐字/逐拍保持 | 该预算只用于音色/风格摘要；完整对白/节拍保持使用原生时间序列干净条件并单独计入预算，交付复用波形 |

这些变化已反映在M16–M20和相关旧文入口，未把需要新训练的部分标成已运行。
