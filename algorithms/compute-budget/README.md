# 单位交付成本的假设演算

这是一个透明的算术工具，用来讨论生成单价与可用率的关系。它不运行视频模型，也不拟合论文中的尺度定律。

假设每次生成独立，达到固定交付标准的概率为 `p`，目标交付 `n` 条，则期望生成次数为 `n / p`。

```text
生成成本 = 期望生成次数 × 每次生成价格
审片成本 = 期望生成次数 × 单次审片秒数 / 3600 × 每小时人工价格
后期成本 = 交付条数 × 单条后期分钟数 / 60 × 每小时人工价格
单位交付成本 = 三者之和 / 交付条数
```

这不是有限预算下的成功保证。不同任务难度、批量相关性、重试策略、失败收费规则、排队延迟、固定投入和客户返工都未建模。

实现见 [budget.py](budget.py)，演示见 [实验目录](../../experiments/2026-11-19-compute-budget/README.md)。价格、可用率和人工时间全部是假设值，未引用为任何厂商实测指标。
