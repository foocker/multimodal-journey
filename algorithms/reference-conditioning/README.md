# 参考控制：上下文、主体与编辑

状态：问题分解，尚未实现训练。

| 任务 | 输入和目标 | 论文入口 |
|---|---|---|
| 多镜头连贯 | 全局角色/环境、镜头提示与历史镜头 → 新镜头或整场景 | [LCT](../../papers/2025/long-context-tuning.md) |
| 主体保持 | 一张或多张主体图、文本指令 → 保持身份的视频 | [Phantom](../../papers/2025/phantom.md) |
| 多轮图像编辑 | 图像与连续编辑指令 → 上下文一致的修改 | [VINCIE](../../papers/2025/vincie.md) |
| 视频编辑迁移 | 视频、编辑要求、图像编辑演示 → 传播一致修改 | [VINCIE-NExT](../../papers/2026/vincie-next.md) |

这些问题都需要拆开“要求改变什么”和“必须保持什么”。主体相同不代表镜头运动正确；动作跟随成功也不保证背景、服装或声音保持。

最小评价应分别评分任务遵循、参考对齐、非目标区域保持、时序稳定和跨镜头一致性。先用 [数据配方](../../datasets/recipes/multishot-reference/README.md) 建立任务，再明确哪些检查可自动化、哪些需要人工判断。
