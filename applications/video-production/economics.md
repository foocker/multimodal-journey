# 商业化：按可交付内容核算

状态：假设与计量方案，尚无真实成本数据。

## 单位成本

```text
每条交付成本 =（生成计费 + 失败/重试计费 + 审片人工 + 后期人工 + 返工 + 固定费用分摊）/ 交付条数
```

同样需要记录交付周期、质量要求与可替代人工流程。客户支付的是解决需求的内容或工作流，单次生成更便宜并不自动代表整体利润更高。

基础演算见 [假设实验](../../experiments/2026-11-19-compute-budget/README.md)。演示数值不能替代供应商价格、实际审片时间和真实交付率。

## 要分别验证的商业假设

| 假设 | 所需证据 | 当前状态 |
|---|---|---|
| 多参考与定向编辑减少重生成 | 固定任务上的候选数、返工和人工时间对照 | 待实验 |
| 更快推理提升吞吐和交付周期 | 端到端延迟、并发限制、排队和稳定性记录 | 待实测 |
| 客户愿为一致性/定制支付溢价 | 访谈、付费试用、真实订单或明确需求 | 未收集 |
| 特定平台支持客户视频 LoRA | 当前官方接口、条款、开放范围与价格 | 待核实 |
| 反馈使用能形成持续改进 | 数据授权、采样与标注设计、训练和前后对照 | 技术研究可参考，具体产品闭环待核实 |

## 采集价格时

记录供应商、产品/模型版本、访问日期、计费单位、分辨率/时长档位、失败退款规则、并发限制和税费/套餐。不同合同和区域不直接混算；没有证据的收入、毛利或市场规模保留为空。
