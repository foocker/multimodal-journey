# 视频内容生产：从演示到交付

状态：研究框架，未完成真实业务验证。

目标任务包括产品广告、短剧情节、讲解片段和多镜头视觉素材。不同任务对品牌/主体保持、声音、字幕、时长和可编辑性的要求不同，应分别建立验收标准。

## 工作流假设

```text
需求/脚本 → 参考与分镜 → 生成候选 → 审片 → 定向编辑或重生成 → 后期 → 交付
```

参考控制如果减少“主体对了但动作错、动作对了但品牌变形”等失败，可能降低候选数与审片时间。推理加速如果只缩短计算而没有提高交付率，商业效果还取决于排队、定价和人工成本。
